
# 🎬 Excel Movie Ratings Analysis

## 📌 Project Overview
This project demonstrates advanced Microsoft Excel skills using a Movie Ratings dataset. It focuses on data formatting, filtering, sorting, conditional formatting, and worksheet management techniques commonly used in data analysis.

---

## 📊 Dataset
The dataset contains movie information such as:

- Movie ID
- Title
- Genre
- Language
- Viewer Name
- Age
- Rating
- Watched Date
- Rewatch Count
- Review Status
